# 快速搭建管理后台框架（前端部分）
## 介绍
#### 项目介绍
1. 所用技术栈：vue3 + vite + ts + element-plus + pinia + axios + vue-router
2. 项目相关功能
   >1.项目工程化
   
     |依赖|版本|功能|官网|备注|
     |---|---|---|---|---|
     |eslint|9.32.0|代码格式检测工具|https://vitejs.dev/|配合vscode的eslint扩展|
     |prettier|3.6.2|代码格式化工具|https://v3.cn.vuejs.org/|配合vscode的（Prettier - Code formatter）展|
     |stylelint|16.9.0|css样式检测工具|https://router.vuejs.org/zh/|配合vscode的Stylelint扩展|
     |unocss|66.4.1|css原子化工具|https://router.vuejs.org/zh/|配合vscode的UnoCSS扩展|
     |vite-plugin-checker|0.10.2|代码检查|https://blog.csdn.net/snowball_li/article/details/149251093||

   >2.按需引入管理

      |方案|说明|链接|
      |---|---|---|
      |unplugin-auto-import|自动import导入|https://element-plus.org/zh-CN/|
      |unplugin-vue-components|组件自动导入|https://element-plus.org/zh-CN/|

      *2.1自动引入说明：*
       - `src\components`目录下组件会自动引入
       - `element-plus`组件会自动引入`
       - `src\assets\icons`目录下svg图标会自动引入

   >3.图标管理

     |方案|说明|链接|
     |---|---|---|
     |unplugin-icons + iconify|iconify图标按需引入|https://icon-sets.iconify.design/|
     |vite-plugin-svg-icons|svg图标使用|https://www.viterc.cn/en/vite-plugin-svg-icons.html|
     
     *3.1图标使用说明：*
      - 自动引入图标：直接在代码中使用图标名称，如：iconify图标：`<Icon icon="ep:edit" />`、本地图标`<Icon icon="local:edit" />`
      - 手动引入图标：在代码中引入图标组件UIcon，如：`<u-icon icon="local:edit" style="font-size: 20px；color: red" />`
      - *-注意-* 本地图标需要在`src/assets/icons`目录下创建图标文件，文件名格式为：图标名称.svg，如：edit.svg
